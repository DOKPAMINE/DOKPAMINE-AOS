# 책 등록 (AOS #24)

- `/book-add`에서 S-20 스캔, S-21 권한 없음, S-22 정보 확인, S-23 직접 입력, S-24 조회 없음, S-25 중복 안내를 제공합니다.
- 카메라는 스캔 화면이 활성화되었을 때만 표시합니다. 권한이 `undetermined`일 때 한 번 요청하고, 거절했으면 다시 요청하지 않습니다. 미리보기가 준비된 뒤 5초 미인식이면 재시도와 직접 입력을 제공합니다.
- ISBN 조회 전에 공통 연결 확인을 사용합니다. 오프라인일 때 요청 없이 `StateView`와 직접 입력 경로를 제공합니다. 조회 중 직접 입력으로 전환하면 늦은 응답을 무시합니다.
- 입력은 RHF + Zod로 검증하며, 대표 장르 목록은 `src/domain/pageRules.ts`의 `GENRES`를 사용합니다. 조회 결과에 필수 정보가 빠졌으면 정보 수정으로 보완합니다.
- ISBN-10/13을 정규화해 비교하고, 공통 기록 저장소의 활성 책을 저장 직전에 다시 확인합니다. 중복이면 기존 책을 변경하지 않고 S-25를 표시합니다. ISBN 없는 직접 입력은 허용하며 삭제 tombstone은 보존합니다.
- 저장은 `initializeDatabase().repository.books.save`만 사용합니다. 저장소가 `syncPending`과 `localVersion`을 설정하고 변경 구독을 통해 동기화를 예약합니다.
- `읽기 시작`은 `READING` 저장 후 `/reading-start?bookId=<UUID>`로 이동합니다. S-40은 6단계에서 구현합니다. `읽고 싶은 책에 담기`는 `WANT` 저장 후 `/book/<id>`로 이동하며 중복 안내도 같은 상세 경로를 사용합니다.

UI는 기존 Noto Sans KR와 브라운 역할 토큰을 유지합니다. 폼은 한 열로 배치하고, 장르 선택은 색과 `선택됨` 문구 및 접근성 checked 상태로 표시합니다. 디자인 스킬의 Accent ladder(시드 531896286)에서 작은 주 동작과 옅은 선택 면의 원칙만 적용했으며, 앱의 기존 토큰과 Android 화면 구조가 우선합니다.

검증 범위는 권한 거절 후 수동 등록, 권한 최초 요청, 5초 미인식, 오프라인/404, 불완전 정보 보완, 늦은 조회 응답, 저장 실패 재시도, 실제 SQLite 중복 행 방지와 tombstone 보존입니다. 연결된 Android 기기가 없어 카메라 실인식과 기기 스크린샷은 확인하지 못했습니다.
