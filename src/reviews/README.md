# 감상과 문장

- S-50: `/book/[id]/review`에서 맨 위에 책의 한줄평 하나, 그 아래에 독후감과 문장을 최신 작성 순으로 읽는다.
  한줄평 영역은 한줄평이 없으면 "한줄평 쓰기", 있으면 "한줄평 수정", 독후감 영역은 "독후감 쓰기" 버튼을 둔다.
- S-51 한줄평: `/book/[id]/review/one-line`에서 100자 입력칸 하나를 저장한다. 한줄평은 책당 하나라
  있으면 채워서 열고 같은 감상을 고친다. 비우거나 바뀐 것 없이 저장하면 막고 안내한다.
- S-53 독후감: `/book/[id]/review/report`에서 5,000자 입력칸 하나를 저장한다. 저장할 때마다 새로 추가한다.
  `?reviewId=`로 열면 그 독후감을 채워 "독후감 수정"으로 열고 같은 ID를 고친다. 비우거나 바뀐 것 없이 저장하면 막는다.
- #91 수정·삭제: S-50의 한줄평·독후감·문장 카드마다 [수정]·[삭제]를 둔다. 한줄평 수정은 S-51, 문장 수정은
  `/book/[id]/review/quote?quoteId=`(예전 메모는 보존)를 쓴다. 삭제는 "삭제할까요? 되돌릴 수 없어요." 확인 뒤
  tombstone(`softDelete`)으로 남겨 동기화한다. 한 감상에 한줄평과 독후감이 함께 든 예전 데이터는 지우는 쪽만 비우고,
  한줄평 삭제는 예전 한줄평이 대신 나타나지 않게 그 책의 한줄평을 모두 지운다. 한줄평이 함께 든 감상의 독후감을 고치거나
  지울 때는 `updatedAt`을 두어 대표 한줄평이 바뀌지 않게 한다.
- 한줄평이 든 충돌 감상이 있으면 해결 전까지 한줄평 쓰기·수정·삭제를 막고 이유를 보여 준다. 충돌한 독후감은 충돌 카드에만
  보이므로 수정·삭제 버튼이 없다. 문장은 서버가 버전을 비교하지 않아 충돌 상태가 없다.
- 공개 범위는 책 단위다(#89). 책 상세(S-31)의 "감상 공개" 스위치가 그 책의 한줄평·독후감 전체를 같은 값으로 바꾸고,
  비공개 → 공개만 확인한다. 쓰기 화면에는 선택이 없고 저장될 공개 범위만 안내한다.
  새 감상은 책의 공개 범위를 따른다. 감상이 없는 책은 스위치로 고른 값을 기기(kv-store, 계정별 키)에만 저장해
  첫 감상에 적용하고, 저장값이 없으면 S-81 기본값(처음엔 비공개)을 따른다. 이 값은 동기화하지 않아 재설치하면 사라진다.
  한줄평 수정은 기존 공개 범위를 유지한다.
- 감상(충돌·삭제 제외)의 공개 범위가 섞인 책은 루트 레이아웃의 `MixedVisibilityPrompt`가 어느 화면에서든 한 권씩
  [모두 비공개]/[모두 공개]로 고르게 한다. 앱 시작, 동기화 종료, 충돌 해결 때 확인하며 예전 데이터와 충돌 해결로
  다시 섞인 경우도 같다. 로그인 전에는 띄우지 않고, S-46 90분 확인창 Modal과 겹치지 않도록 독서 타이머
  화면(`/reading-start`)에 있는 동안에는 미뤘다가 나가면 띄운다.
- 공개 범위만 바꿀 때는 감상의 `updatedAt`을 두고 `localVersion`·`syncPending`만 바꾼다. 대표 한줄평이
  `updatedAt` 순이라 공개 범위 변경으로 바뀌지 않게 하기 위해서다. 서버는 충돌을 `version`으로 판단한다.
- S-52: `/book/[id]/review/quote`에서 문장과 선택 쪽수·메모를 저장한다.
- D-03: 입력 변경 후 닫기·Android 뒤로 가기 시 확인한다. Expo Router의 `usePreventRemove`를 사용한다.

입력 검증은 `src/domain/reviewRules.ts`의 Zod 스키마가 담당한다. 한줄평 100자,
독후감 5,000자, 문장 1,000자, 선택 메모 500자까지 허용한다.
쪽수는 빈 값이면 null, 값이 있으면 0 이상의 안전한 정수다.

모든 저장은 공통 기록 저장소를 이용하며 서버를 직접 호출하지 않는다.
저장소가 UUID와 `syncPending`·버전을 관리하고 화면은 변경을 구독한다.
새 UUID는 작성 화면에서 한 번 생성해 저장 재시도에도 유지한다.
저장 실패 시 입력을 유지하고, 저장 성공 후 기존 목록으로 돌아간다.

경계값 테스트는 `src/domain/__tests__/reviewRules.test.ts`, 실제 SQLite를 사용하는
라우트 통합 테스트는 `src/reviews/__tests__/reviews.test.tsx`에 있다.
